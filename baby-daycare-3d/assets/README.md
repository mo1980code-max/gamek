# assets/

This folder is intentionally empty of binary assets.

**Every model, texture, sound and icon in this game is generated procedurally at runtime:**

- `assets/models/` → 3D characters & furniture are built from Three.js primitives (`js/kit.js`, `js/baby.js`, `rooms/*`)
- `assets/textures/` → canvas-generated (TV cartoon, sprites, gradient skies)
- `assets/sounds/` → synthesized live with the Web Audio API (`js/audioManager.js`)
- `assets/music/` → 8 sequenced original tunes, generated by the built-in step sequencer
- `assets/icons/` → emoji sprites rendered to canvas textures

To drop in production-grade recorded audio later, place files under `sounds/` and load them via `AudioContext.decodeAudioData` — `audioManager.js` is structured so synth recipes can be swapped for buffers without touching the game code.
