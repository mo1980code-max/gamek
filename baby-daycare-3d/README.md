# 🍼 Baby Jini 3D Daycare Adventure

لعبة حضانة أطفال ثلاثية الأبعاد كاملة تعمل في المتصفح — HTML5 + CSS3 + JavaScript ES6 + Three.js + Web Audio API.
بدون أي ملفات نماذج أو صوتيات خارجية: كل الشخصيات والأثاث والغرف مبنية **Procedural 3D Geometry**، وكل الأصوات والموسيقى مولّدة بـ **Web Audio API**.

A complete, playable 3D baby-daycare game for phones, tablets and desktop. No installs, no build step, no external assets.

---

## ▶️ التشغيل | Run

```bash
cd baby-daycare-3d
python3 -m http.server 8000 --bind 0.0.0.0
# ثم افتح http://localhost:8000
```

أو أي خادم ملفات ثابت آخر. لا حاجة لأي خطوة بناء — افتح `index.html` عبر خادم محلي فقط (بسبب ES Modules).

**Requirements:** any modern browser (Chrome/Edge/Firefox/Safari). Import-map polyfill (`es-module-shims`) مضمّن للمتصفحات الأقدم.

## 👶 المميزات | Features

| النظام | التفاصيل |
|---|---|
| **6 شخصيات 3D** | جيني، ميمي، توتو، لولو، كوكو، نونو — رؤوس كبيرة، عيون معبّرة، 17 حركة (مشي، ركض، نوم، أكل، بكاء، ضحك، رقص، تصفيق، سباحة…) و13 تعبير وجه |
| **20 غرفة 3D** | نوم، استحمام، طعام، ملابس، ألعاب، مطبخ، عيادة، حفاضات، حديقة، رسم، موسيقى، تعليم، غسيل، متجر، أعياد ميلاد، مسبح، حيوانات، ألغاز، قصص، الصالة الرئيسية |
| **أنشطة حقيقية** | كل غرفة فيها تفاعلات فعلية: خطوات مُوجّهة، سحب وإفلات، فيزياء (أرجوحة/كرة/ترامبولين)، ماء متحرك، جسيمات (فقاعات/نجوم/ZZZ/كونفيتي) |
| **ألعاب مصغّرة قابلة للعب** | برج المكعبات، تسديد السلة، فرز الأشكال، سباق القوارب، تلوين Canvas (تعبئة/فرشاة/ملصقات/حفظ PNG)، بيانو وإكسيليفون حقيقيان، لعبة تقليد النغمات، تركيب صور، ذاكرة، ظلال، متاهة، بحث عن أشياء، مطابقة، فرز |
| **نظام احتياجات** | جوع/طاقة/سعادة/نظافة/صحة/راحة — تتناقص تدريجيًا مع AI حالات (HUNGRY, SLEEPY, DIRTY…) وفقاعات تعبير فوق الرأس |
| **صوت 100% مولّد** | ~60 مؤثرًا (بكاء، ضحك، ثبات، شخير، ماء، أدراج، حيوانات…)، 7 آلات موسيقية، 8 مقطوعات خلفية (تهويدة، عيد ميلاد…) + متابِع نغمات lookahead |
| **مهام ومكافآت** | 12 مهمة يومية بشريط تقدم + عملات 🪙 ونجوم ⭐ + احتفالات |
| **متجر** | شراء بالعملات المكتسبة من اللعب فقط — المشتريات تظهر فعلًا في الغرف |
| **حفظ تلقائي** | localStorage: عملات، ملابس، احتياجات، مهام، إعدادات، أرقام قياسية |
| **دعم كامل** | لمس (tap/drag/pinch/long-press) + فأرة، RTL عربي، متجاوب Mobile-First، تحجيم جودة تلقائي للهواتف الضعيفة |

## 🗂️ البنية | Structure

```
baby-daycare-3d/
├── index.html            شاشة التحميل والقائمة وHUD
├── style.css             واجهة أطفال متجاوبة RTL
├── main.js               نقطة الدخول
├── lib/                  three.module.min.js + es-module-shims (مضمّنة)
├── js/                   المحرك: game, sceneManager, camera, controls
│                         (interactionManager), audioManager, babyAI,
│                         babyAnimations, baby, roomBase, particles, kit,
│                         taskManager, rewardSystem, saveSystem, uiManager
├── characters/           الإعدادات الست للشخصيات
├── rooms/                الغرف العشرون + السجل index.js
├── minigames/            coloring, puzzles, cooking, music, matching, sorting
├── tools/smoke-test.mjs  اختبار شامل headless (Node + three حقيقي)
└── assets/               فارغة عمدًا — كل الأصول مولّدة برمجيًا
```

## 🧪 الاختبار | Testing

```bash
npm install          # three (للاختبار فقط)
npm run check        # يبني كل غرفة ويجرب كل تفاعل وحركة وتعبير headless
```

يغطي: بناء الغرف العشرين، الدخول/الخروج، 120 إطار تحديث لكل غرفة، كل نقرة وسحب على كل عنصر تفاعلي، كل الحركات والتعبيرات للشخصيات الست، كل الألعاب المصغرة، وجولة حفظ/استعادة.

## 🔊 ملاحظة إنتاجية عن الصوت

كل الأصوات مولّدة بـ Web Audio API لتعمل بدون أي ملفات. للحصول على جودة إنتاجية نهائية يمكن استبدال مؤثرات الشخصيات (البكاء/الضحك/المناغاة) بتحجيلات مسجّلة حقيقية للأطفال في `assets/sounds/` عبر `AudioBufferSourceNode` — البنية جاهزة لذلك في `audioManager.js`.

## 🏆 الأداء

- Pixel Ratio محدود بـ 2 (و1 في وضع التوفير)
- إخماد الظلال تلقائيًا عند انخفاض FPS (< 38)
- تجميع المواد (Material Cache) وتخزين الغرف مرة واحدة
- Particle pooling بمصفوفات ثابتة
- تحديث الاحتياجات المخففة خارج الشاشة
