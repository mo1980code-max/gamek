# 🍼 Baby Jini 3D Daycare Adventure

A complete 3D baby-daycare HTML5 game (Three.js + Web Audio, zero external assets).

**Play:** open a terminal in `baby-daycare-3d/` and run
`python3 -m http.server 8000 --bind 0.0.0.0` → open `http://localhost:8000`.

See [baby-daycare-3d/README.md](baby-daycare-3d/README.md) for the full feature list, architecture, and testing instructions.
